傅里叶级数可视化 · 用一堆正弦波，拼出一个方波

SN(x) = 4/π [ sin x + (sin3x)/3 + (sin5x)/5 + … (sin(2N−1)x)/(2N−1) ]  →  方波（所有 cos(nx) 项为 0）

拖动滑块调 N （正弦波个数）：N=1 圆滚滚 → N=5 出肩膀 → N=20 有棱角 → N=40 几乎和方波重合。把鼠标挪到波形上，会出现放大镜，观察拐角处的吉布斯现象。

部分和 SN(x)（正弦波的叠加） 目标方波（参考线） 悬停放大镜（看吉布斯现象）
f方波(x) ≈ SN(x) = 4/π Σk=1..N sin((2k−1)x) / (2k−1)
展开式里只有奇次正弦项（1, 3, 5, 7, …）：
　　1·sin x ＋ (1/3)·sin 3x ＋ (1/5)·sin 5x ＋ (1/7)·sin 7x ＋ …
各余弦项系数均为 0·cos(nx)（灰色）——因为方波是奇函数，奇 × 偶（cos）= 奇，对称区间积分为 0。
玩法：① 拖滑块——看橙色曲线一步步长出棱角；② 点自动播放——N 从 1~40 来回循环；③ 悬停放大镜——对准方波拐角，能看见 N 再大也消不掉的过冲与抖动（经典吉布斯现象：峰值约 1.18，比平台 1 高出约 18%；按跳跃幅度计约为 9%）。
