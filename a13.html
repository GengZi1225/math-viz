3D 特殊平面图鉴 · Ax + By + Cz + D = 0 的 13 种样子

平面一般方程 Ax + By + Cz + D = 0　（A、B、C 是系数，D 是常数项）

参数一变，平面就挪。常见特殊情形共 13 种：过原点、平行/包含坐标轴、平行/重合坐标面。左侧点平面，右侧拖拽旋转 · 滚轮缩放，方程与立体同屏对照。

x + y + z = 0
D=0 → 平面一定过原点 (0,0,0)，斜穿八个卦限。

记忆口诀

缺哪个字母 → 平行于哪个轴；缺字母且 D=0 → 包含那个轴。
只剩一个字母 = 常数 → 平行于坐标面；= 0 → 重合坐标面。
注意：包含轴的平面不一定是竖直的（如 y−z=0 与 yoz 面成 45°）。
