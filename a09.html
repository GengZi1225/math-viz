几何级数可视化 · 公比 q 决定收敛还是发散

级数 1 + q + q² + q³ + …（公比 q）　⇒　|q|<1 收敛（和 S = 1/(1−q)）　｜　|q|≥1 发散

左图：级数项 uₙ = qⁿ 的柱状图（蓝 = 正项，红 = 负项）—— |q|<1 柱子越来越矮，|q|>1 柱子越来越高；右图：部分和 Sₙ 的折线轨迹（蓝线，红虚线 = 极限和 S，仅收敛时出现）。

① 级数项 uₙ = qⁿ（柱状图）
uₙ > 0 uₙ < 0 柱子矮→趋零（收敛项）；柱子高→指数增长（发散项）
② 部分和 Sₙ = 1+q+…+qⁿ（折线轨迹）
Sₙ 轨迹 极限和 S = 1/(1−q)（仅 |q|<1） 收敛：折线贴向红线；发散：冲天或震荡
q 公比
